Welcome to Line MindMap support. This page provides basic troubleshooting guidance and the official channel for reporting problems, requesting help, and sharing feedback.

Common issues

Google sign-in is blocked

Make sure you are signing in with the Google account that has permission to use the application. If Google shows an OAuth testing or verification message, the application owner may still be completing Google's review process.

My map is not appearing in Google Drive

Confirm that you granted the requested Google Drive permissions and that you are signed into the intended Google account. The App stores App-managed mind maps in your own Google Drive.

Saving failed

Check that you are online, refresh the page, and try Save again. Line MindMap can also keep working locally in the browser when Google Drive is unavailable.

A Drive file will not open

Make sure the file is a Line MindMap file created by the App or a file that you explicitly opened through the supported Google Drive integration. Also confirm that the Google account currently connected to the App has access to the file.

How to report a problem

Please use the project's official GitHub issue tracker:

Open a Line MindMap support issue

When reporting a technical problem, include the browser you are using, the approximate time of the problem, the action that failed, and the exact error message when available. Do not post passwords, OAuth tokens, private Drive links, or other sensitive information in a public issue.

Feature requests and feedback

Suggestions are welcome through GitHub Issues. Please describe the problem you are trying to solve and, where possible, give an example of the workflow you would like Line MindMap to support.
