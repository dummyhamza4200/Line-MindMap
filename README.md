# Line MindMap

Line MindMap is a browser-based medical study workspace for organizing complex topics through visual mind maps and structured tables.

Official website: https://linemindmap.com/

## Product

- Medical-student focused mind mapping and study organization
- Structured comparison tables
- Notes, rich text, and images
- Keyboard-first editing
- Export workflows
- Browser-only local storage
- Optional Google Drive-backed saving and opening

## Scope

Line MindMap is educational productivity software. It is not a medical reference, diagnostic system, clinical decision-support system, or substitute for clinical guidelines, peer-reviewed literature, institutional protocols, or professional medical advice.
